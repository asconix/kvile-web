type Session = { name: string; hours: number };

// Calm by default, bright only where it matters.
const MAX_HOURS = 8;
const pattern = /^kvile-(\w+)$/i;

export function schedule(s: Session): string {
  if (s.hours > MAX_HOURS) {
    throw new Error("Take a break: " + s.hours);
  }
  return s.name.replace(pattern, "$1");
}

Why Kvile

Quiet colors, built with math.

Most themes are picked by eye and checked never. Kvile is generated, measured, and then tuned by eye.

Four variants, one system

Night, dusk, day and high contrast share the same roles and the same checks. Pick one, the whole page follows.

Contrast you can trust

7.4:1

Text on background in the current variant. Comments stay readable at 4.6:1 instead of fading away.

Safe for colorblind eyes

ΔE ≥ 6

Every pair of syntax colors stays separable under deuteranopia, protanopia and tritanopia. The build fails if one slips.

Designed in OKLCH

Accents are defined by perceptual lightness and chroma instead of hex guesses, so yellow does not shout over purple. Each hue is nudged only as far as it takes to stay distinct.

Accessibility

Proof, not promises.

Contrast is measured with WCAG ratios. Colorblind separation uses the Machado simulation and OKLab distance, where about 2 is just noticeable and Kvile enforces 6 or more.

Install

Two minutes to calmer.

Everything lives in the repository. Variants are Natt, Skumring, Dag and Kontrast.

VS Code
git clone https://github.com/asconix/kvile.git
cd kvile/ports/vscode
ln -s "$(pwd)" ~/.vscode/extensions/asconix.kvile-0.1.0

Reload VS Code, then run "Preferences: Color Theme" and pick a Kvile variant.

Ghostty
cp ports/terminal/ghostty/kvile-* ~/.config/ghostty/themes/

In your Ghostty config: theme = kvile-natt

Alacritty
mkdir -p ~/.config/alacritty/themes
cp ports/terminal/alacritty/*.toml ~/.config/alacritty/themes/

In alacritty.toml: general.import = ["~/.config/alacritty/themes/kvile-natt.toml"]

kitty
cp ports/terminal/kitty/*.conf ~/.config/kitty/

In kitty.conf: include kvile-natt.conf

WezTerm
mkdir -p ~/.config/wezterm/colors
cp ports/terminal/wezterm/*.toml ~/.config/wezterm/colors/

In wezterm.lua: config.color_scheme = "Kvile Natt"

iTerm2
open ports/terminal/iterm2/kvile-natt.itermcolors

Or: Settings > Profiles > Colors > Color Presets > Import.

Windows Terminal
ports/terminal/windows-terminal/kvile-schemes.json

Paste the entries into the schemes array in settings.json, then set colorScheme on your profile.
